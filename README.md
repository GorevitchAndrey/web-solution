# Easy Web Solution — Calgary Web Design & Development

**Live site:** https://easy-web-solution.com

Easy Web Solution is my web design and development portfolio focused on business websites, custom web applications, website fixes, and modern frontend work for businesses in Calgary and beyond.

The project is built with **Next.js 14, React, TypeScript, and modern CSS**, and is deployed on **Vercel**.

## Technical / SEO foundation

The portfolio includes:

- semantic, crawlable page structure
- responsive design
- canonical URLs
- generated sitemap and robots rules
- structured data for services, breadcrumbs, and long-form guides
- Google Search Console integration
- internal links between services, case studies, guides, and contact pages
- production deployment on Vercel

## Main stack

- Next.js 14
- React
- TypeScript
- CSS
- Vercel

Additional professional experience includes Node.js, Firebase, APIs, dashboards, messaging systems, automotive inspection interfaces, and custom business workflows.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash

```
